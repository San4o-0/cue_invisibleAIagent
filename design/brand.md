# Cue — бренд

Cue — помічник для дзвінків і співбесід. Він слухає співрозмовника й за гарячою клавішею тихо підказує коротку відповідь. Назва від театрального «cue»: так називають сигнал актору, що пора виходити на сцену.

## Лого

Знак — це літера «c», яка водночас є хмаринкою репліки. У її «роті» горить лампа-сигнал.

| Файл | Де використовувати |
|---|---|
| `logo/cue-symbol.svg` | знак на темному фоні |
| `logo/cue-symbol-mono.svg` | одноколірний друк, вишивка, штампи |
| `logo/cue-app-icon.svg`, `../Assets/cue.ico` | іконка програми, панель задач (16–256 px) |
| `logo/cue-lockup.svg` | знак + назва «cue» для шапок, слайдів |

- Назва пишеться малими літерами: **cue**, шрифт Manrope ExtraBold.
- Мінімальний розмір знака — 16 px. На 16 px хвостик репліки зливається, «c» і лампа лишаються.
- Лампа завжди окремого кольору: бірюзова на темному фоні, темно-бірюзова `#0E9C93` на світлому. В одноколірному варіанті вона того ж кольору, що й знак.
- У програмі лампа в лого показує стан: бірюзова — «слухаю», бурштинова й пульсує — «готую підказку», сіра — пауза.

## Кольори

| Назва | HEX | Роль |
|---|---|---|
| Night | `#0F1A22` | фон вікна |
| Deep | `#16242D` | поля, блоки |
| Line | `#26404C` | рамки, неактивна частина повзунка |
| Ink | `#E6EEF2` | основний текст |
| Mist | `#8FA3AE` | другорядний текст |
| Hint | `#7A919D` | текст порожніх станів |
| Cue | `#3FD1C7` | головна дія, стан «слухаю», лампа |
| Standby | `#F5B84A` | стан «готую підказку» |
| Alert | `#FF6B6B` | помилки, «видно в демонстрації» |

Контраст (WCAG): Ink на Night 15:1, Mist на Deep 6,1:1, Hint на Deep 4,8:1, Night на Cue 9,4:1, Alert на Deep 5,7:1. Усі пари проходять AA для звичайного тексту.

Правила:
- Бірюзовий — лише для головної дії та стану «готово/слухаю». Не для декору.
- Стан ніколи не передається тільки кольором: поруч завжди є слово або іконка.

## Шрифт

Manrope (OFL, з кирилицею), вбудований у програму: `Fonts/`, ліцензія `Fonts/OFL.txt`.

| Роль | Накреслення | Розмір |
|---|---|---|
| Назва «cue» | ExtraBold | 19 |
| Заголовки блоків | Bold | 14 |
| Кнопки | SemiBold / Bold | 13.5–14 |
| Текст, підказки | Regular | 14–15.5 |
| Допоміжний текст | Regular | 12.5 |

Іконки — Segoe MDL2 Assets (системний шрифт Windows).

## Тон

Пишемо від імені Cue простими словами, без технічних термінів. Дія називається однаково всюди: кнопка «Підказати», статус «Підказка готова». Помилки кажуть, що сталося і що зробити, без вибачень.
